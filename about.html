요약: 이 사이트는 서버에 아무것도 저장하지 않아요. 노트·시간표·API 키는 여러분 기기의 브라우저 안에만 저장되고, 받아쓰기와 AI 정리를 위해 필요한 내용만 여러분이 고른 회사(구글, Anthropic)로 직접 전송돼요.

어떤 서비스인가요

수업을 들으면서 소리를 글로 받아쓰고, AI가 그 글을 필기 노트로 정리해 주는 무료 웹 앱이에요. 개인이 만든 비영리 프로젝트이며, Anthropic·Google·연세대학교 등 어떤 회사·기관과도 관련이 없어요.

  • 운영자는 여러분의 노트, 녹음, API 키를 볼 수도, 받을 수도 없어요. 방문자 수 집계나 광고 추적도 하지 않아요.
  • AI 회사로 보낸 내용은 각 회사의 정책을 따라요. 특히 Gemini 무료 등급은 보낸 내용이 구글 제품 개선에 쓰일 수 있어요. (Gemini API 약관, Anthropic 개인정보 처리방침)
  • 브라우저 데이터를 지우거나 기기를 바꾸면 노트가 사라져요. 📚 노트함 → 💾 백업으로 가끔 저장해 두세요. 아이폰 Safari는 오래 안 쓴 사이트의 데이터를 지울 수 있으니 홈 화면에 추가해서 쓰는 걸 권해요.

API 키 안내

  • AI 정리는 본인의 API 키로 동작해요. 사용료는 키 주인에게 직접 청구되고, Claude 구독(Pro 등)과는 별개예요.
  • Anthropic 콘솔이나 Google AI Studio에서 월 사용 한도를 걸어두세요. 키를 남에게 보내거나 공개된 곳에 올리지 마세요.
  • 키는 이 브라우저에만 저장되며, 설정에서 언제든 지울 수 있어요.

녹음과 저작권

  • 녹음하기 전에 교수님께 동의를 받아주세요. 학교·수업마다 녹음 규정이 다를 수 있어요.
  • 강의 내용과 강의자료의 저작권은 교수님(또는 저작권자)에게 있어요. 만든 노트는 개인 학습용으로만 쓰고, 녹음·노트·강의자료를 다른 곳에 올리거나 판매하지 마세요.
  • 다른 학생의 발언이 받아써질 수 있으니 노트를 공유할 땐 주의해 주세요.

책임의 한계

  • 받아쓰기와 AI 정리에는 오류가 있을 수 있어요. 특히 시험 범위·과제 기한 같은 📌 중요 항목은 반드시 강의 공지·LearnUs 등 공식 안내로 다시 확인하세요.
  • 이 서비스는 있는 그대로 무료로 제공되며, 예고 없이 바뀌거나 중단될 수 있어요.
